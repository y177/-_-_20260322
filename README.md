# 📚 이야기 동화관 (Story to Storybook)

> 아이가 말한 이야기를 AI가 예쁜 동화책으로 만들어주는 웹 앱입니다.
> 놀이치료 현장에서 아이들의 이야기를 소중히 기록하고 시각화할 수 있습니다.

---

## 1. 프로그램 소개

**이야기 동화관**은 아이가 들려준 이야기를 입력하면, AI(Google Gemini)가 자동으로:

- 이야기를 4~6개의 장면으로 분리
- 각 장면에 어울리는 동화책 스타일 삽화 생성
- 페이지를 넘기는 인터랙티브 동화책으로 완성
- 이미지를 ZIP 파일로 다운로드

하는 웹 기반 자동화 도구입니다.

| 항목 | 내용 |
|------|------|
| 사용 대상 | 놀이치료사, 유아교육 담당자, 특수교육 교사 |
| 배포 방식 | 웹 앱 (브라우저 접속) — 별도 설치 불필요 |
| 필요 조건 | Google Gemini API 키 (무료 발급 가능) |
| 데이터 보안 | API 키는 본인 기기 브라우저에만 저장, 서버 전송 없음 |

---

## 2. 실행 방법 (사용자용)

### 2-1. 처음 사용할 때

**① 웹 앱 주소로 접속합니다**
→ 팀에서 공유한 Netlify 주소(예: `https://your-app.netlify.app`)를 브라우저에서 엽니다.

**② Gemini API 키를 발급받습니다**
→ [Google AI Studio](https://aistudio.google.com)에 접속
→ 우측 상단 **"Get API key"** 클릭
→ **"Create API key"** 클릭
→ 발급된 키(`AIza...`로 시작)를 복사

**③ API 키를 앱에 입력합니다**
→ 앱의 **"🔑 API 키 설정"** 버튼 클릭
→ 복사한 키를 붙여넣기
→ **"저장하기"** 클릭
→ ✅ 확인 메시지가 뜨면 완료

**④ 이야기를 입력합니다**
→ 텍스트 창에 아이가 말한 이야기를 입력
→ **"✨ 동화책 만들기"** 클릭

**⑤ 완성된 동화책을 확인합니다**
→ 이미지가 순서대로 생성됩니다 (장면당 약 10~30초 소요)
→ **"← 이전 / 다음 →"** 버튼으로 페이지 이동
→ **"🖼️ 갤러리"** 탭에서 전체 이미지를 한눈에 확인
→ **"📥 ZIP 다운로드"**로 이미지 파일 저장

## 3. 주요 기능 설명

| 기능 | 설명 |
|------|------|
| **이야기 입력** | 자유 형식의 한국어 이야기 입력 (예시 이야기 버튼 제공) |
| **AI 장면 분리** | Gemini AI가 이야기를 4~6개 장면으로 자동 분리 |
| **이미지 생성** | 각 장면을 수채화 동화 스타일 삽화로 자동 생성 |
| **동화책 뷰어** | 페이지 넘김 애니메이션이 있는 인터랙티브 뷰어 |
| **갤러리 보기** | 모든 장면 이미지를 한 화면에서 확인 |
| **전체화면** | 동화책을 전체화면으로 감상 |
| **ZIP 다운로드** | 생성된 모든 이미지를 ZIP 파일로 저장 |
| **API 키 관리** | 키를 브라우저에 안전하게 저장, 언제든 변경 가능 |

## 4. 개발자용 실행 방법

### 필요 환경
- Node.js 20 이상
- npm 또는 yarn
- Google Gemini API 키

### 로컬 개발 서버 시작

```bash
# 1. 패키지 설치
npm install

# 2. Netlify CLI 설치 (처음 한 번만)
npm install -g netlify-cli

# 3. 개발 서버 시작 (Netlify Functions 포함)
netlify dev
```

브라우저에서 `http://localhost:8888` 접속

### 프로덕션 빌드

```bash
npm run build
```

빌드 결과물은 `dist/` 폴더에 생성됩니다.

## 7. 자주 묻는 질문 (FAQ)

**Q. API 키가 뭔가요? 유료인가요?**
A. Google Gemini API 키입니다. Google AI Studio에서 무료로 발급받을 수 있으며, 무료 플랜으로도 충분히 사용 가능합니다.

**Q. API 키는 안전한가요?**
A. 키는 오직 사용자 본인의 브라우저(localStorage)에만 저장됩니다. 서버나 다른 곳으로 전송되지 않습니다.

**Q. 이미지 생성이 너무 오래 걸려요.**
A. 장면 하나당 10~30초가 소요됩니다. Netlify 무료 플랜의 경우 함수 타임아웃이 8초이므로 일부 이미지가 생성되지 않을 수 있습니다. 그 경우 해당 페이지는 빈 상태로 표시됩니다.

**Q. 일부 이미지가 생성되지 않았어요.**
A. API 사용량 한도나 타임아웃 때문일 수 있습니다. 잠시 후 다시 시도하거나, 이야기를 더 짧게 입력해보세요.

**Q. 동화책을 저장하고 싶어요.**
A. "📥 ZIP 다운로드" 버튼을 클릭하면 생성된 이미지 파일들이 ZIP으로 저장됩니다.

**Q. 다른 사람도 사용하게 하고 싶어요.**
A. Netlify URL을 공유하기만 하면 됩니다. 각 사용자가 본인의 Gemini API 키를 입력해서 사용합니다.

## 8. 문제 발생 시 대처 방법

| 에러 메시지 | 원인 | 해결 방법 |
|------------|------|-----------|
| "유효하지 않은 API 키" | API 키가 잘못됨 | Google AI Studio에서 키를 재발급 후 다시 입력 |
| "API 사용량 한도 초과" | 무료 플랜 한도 초과 | 잠시 후 다시 시도 (분당/일별 한도) |
| "이미지 생성 시간이 초과" | 서버 처리 지연 | 자동으로 다음 장면으로 넘어감, 재시도 가능 |
| "이야기 분석에 실패" | 네트워크 오류 | 인터넷 연결 확인 후 재시도 |
| 화면이 뜨지 않음 | 브라우저 캐시 문제 | Ctrl+Shift+R로 강제 새로고침 |

**로그 확인 방법:**
브라우저 개발자 도구(F12) → Console 탭에서 실행 로그를 확인할 수 있습니다.
또는 브라우저 개발자 도구 → Application → Local Storage → `app_logs` 항목에서 저장된 로그를 확인하세요.
